# 図

[English Version](README.md)

このディレクトリには、文明存続の比較シナリオモデルから生成されたグラフが含まれています。

**これらはシナリオモデルの可視化であり、実証データのグラフでも、科学的な予測でもありません。**
すべての図は、正規化されたトイモデルの出力から作成されています。価値体系の違いの論理を、視覚的に検査し、比較できるよう設計されています。

---

## 再生成の方法

リポジトリのルートから：

```bash
python simulator/run_all_simulations.py
```

あるいは、既存のCSVから図だけを再生成：

```bash
python simulator/generate_civilization_figures.py
```

必要環境：`matplotlib`（`pip install matplotlib`）

## 図の説明

### 生存可能性の折れ線グラフ

| ファイル | 説明 |
|---|---|
| `civilization_survival_warming.png` | 温暖化のみのストレスのもとでの、2025〜2200年の生存可能性。三つのフレームワーク、不確実性の帯付き |
| `civilization_survival_el_nino.png` | エルニーニョのみのストレスのもとでの、2025〜2200年の生存可能性。三つのフレームワーク |
| `civilization_survival_combined.png` | 温暖化＋エルニーニョの複合ストレスのもとでの、2025〜2200年の生存可能性 |

### 要因の内訳チャート

| ファイル | 説明 |
|---|---|
| `warming_driver_breakdown.png` | フレームワークごとの、2050年、2100年、2200年における各温暖化要因の相対的な寄与 |
| `el_nino_driver_breakdown.png` | フレームワークごとの、2050年、2100年、2200年における各エルニーニョ要因の相対的な寄与 |

### 比較チャート

| ファイル | 説明 |
|---|---|

| `framework_radar_comparison.png` | 三つのフレームワークにわたる、六つの主要なパラメータ次元を比較するレーダーチャート |

### ヒートマップ

| ファイル | 説明 |
|---|---|
| `warming_survival_heatmap.png` | フレームワークとサンプリングした年ごとの生存可能性指標（温暖化シナリオ） |
